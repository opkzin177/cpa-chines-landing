# CPA Chinês Landing Page

Landing page limpa e otimizada para conversão, construída com HTML puro e pronta para deploy no Netlify.

## 🚀 Tecnologias

- **HTML5** semântico e acessível
- **CSS** moderno (responsivo)
- Deploy contínuo via **Netlify**

## ✨ Destaques

- Código limpo e leve (sem frameworks desnecessários)
- Foco em performance e SEO básico
- Pronto para integração com ferramentas de analytics e pixels de conversão

## 📂 Estrutura

```
cpa-chines-landing/
├── index.html      # Página principal
└── README.md
```

## 🛠️ Como rodar localmente

Basta abrir o `index.html` no navegador ou usar um servidor estático simples:

```bash
npx serve .
```

## 📦 Deploy

Conecte o repositório ao Netlify e publique a pasta raiz.
